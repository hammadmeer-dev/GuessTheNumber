# Contributing

Thanks for helping improve GuessTheNumber!

## Suggested workflow

1. Open an issue describing a bug or improvement before making a substantial change.
2. Create a focused branch from `main`.
3. Keep changes small and explain the behavior they affect.
4. Test the game manually, including a correct guess, an incorrect guess, and restarting a round when supported.
5. Open a pull request describing what changed and how you tested it.

Please avoid committing generated files, secrets, or unrelated formatting changes.
